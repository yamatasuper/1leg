## 1. Саммари
Единый визуальный мир Прибрежья: пост-советский реализм, выцветшие краски, индустриальный пейзаж, эмоция кадра важнее «красивого футбола». ИИ можно использовать только с обязательным human pass (`art_pipeline`). Матч в игре — комикс-панели / иллюстрации + Ken Burns, не FIFA-рендер.

## 2. AI contract (читать перед генерацией)

Ты — художник игры «90 минут». Каждый кадр — состояние Бардина, не спорт-постер.

**Сначала:** этот файл + паспорт героя из сюжетной библии + style prefix.  
**Потом:** один `art_id` за раз. Не смешивай нескольких героев в одном промпте, если карточка не просит групповой кадр.

### Обязательный выход
1. `art_id` + тип (`portrait` / `location` / `key_art` / `ui` / `transition`)
2. RU brief (кто, где, эмоция, что в кадре, что за кадром)
3. English prompt
4. negative prompt
5. камера / свет / палитра
6. must-have детали (3–7)
7. must-not (клише)
8. заметка для human pass (где ИИ обычно врёт)

### Запрещено
- аниме, героический FIFA-постер, солнечный сток, киберпанк-неон
- читаемый выдуманный текст кроме канона (`Бардин 8`, `Бардин — легенда`, граффити из библии)
- лишние пальцы, watermark, plastic skin, «AI glow»
- делать Бардина молодым фитнес-моделью
- западноевропейский премьерлиговый стадион вместо «Торпедо»

### После генерации
Не считать кадр готовым. Чеклист human pass — §11 и `art_pipeline`.

## 3. Стиль-лок (этот файл главнее `art_pipeline`)

Пайплайн 12 августа (human pass, Ken Burns, запрет as-is, cut order) — техника. **Палитра, персонажи, локации, обложка, prompt prefix — отсюда.** Если старый prefix спорит с новым — новый.

**Стиль:** реалистичный, депрессивный эстетизм, лёгкая плёночная стилизация, пост-советский индустриальный пейзаж. Не FIFA-рендер, не аниме. Матч-панели — та же кровь, более собранный фокус.

**Эталоны настроения (не копировать лица/кадры):**
пост-советские индустриальные фото; The Last of Us (упадок); Disco Elysium (палитра, грязь, человечность); Life is Strange (свет как эмоция); S.T.A.L.K.E.R. (пост-совет); Эндрю Уайет; Репин; советские плакаты 70-х только как палитра; фильмы «Брат», «Левиафан», «Остров», «Возвращение».

**Палитра:**
- серый — небо, бетон
- жёлтый — пальто, баннеры, выгоревшая трава (акцент, не залив)
- синий — река, ночь
- коричневый — дерево, ржавчина
- кожа — приглушённая, не глянец
- редкий золотой просвет на горизонте = не «хеппи», а прощание

**Свет:** мягкий естественный, часто контровой. Раздевалка — тёплая лампа. Больница — стерильный белый. Ресторан — свечи. Завод — грязные окна, длинные тени.

**Обработка:** лёгкое зерно, тёплая или холодная коррекция по локации, виньетка на флэшбеках.

### Stable prompt prefix
Не менять mid-project без записи в историю.

```
muted cinematic still, post-soviet industrial melancholy, consistent real human faces, faded paint, rust and damp concrete, dirty yellow grass, grey sky, film grain, naturalistic light, no watermark, no extra limbs, no unreadable random text, not a sports video game screenshot, not anime
```

Для матч-панелей добавь в конец: `comic panel framing, clear focal action, same world and palette, not manga speedlines overload`.

### Negative prompt (всегда)

```
anime, manga eyes, FIFA, eFootball, Unreal Engine sports screenshot, neon cyberpunk, stock sunset couple, plastic skin, extra fingers, extra legs, watermark, logo, unreadable text, beauty filter, stadium fireworks, packed Premier League crowd, heroic low-angle poster, cheerful commercial photography
```

## 6. Ключевые арты (приоритет)

Генерировать в этом порядке, если времени мало: 1 → 3 → 2 → 8 → 9, остальное позже. Вариации матч-панелей режутся первыми (`art_pipeline`).

### `art_key_cover` — обложка
Бардин на «Торпедо» **спиной**. Смотрит на реку за воротами. Серое небо, золотистый просвет. Выцветшая форма. Запад: баннер «Бардин — легенда». В руках старый мяч. Прощание, не постер победы.
Композиция: силуэт в центре, река сзади, стадион обрамляет.

### `art_key_locker` — раздевалка
Бардин бинтует ногу. Глок смотрит на него. Пень в углу в телефон. Сокол в наушниках. Длинные тени. Тёплая лампа. Усталость и ожидание.

### `art_key_face` — лицо на поле
Крупно. Смотрит вверх. Морщины, усталость, лёгкая улыбка принятия. Стадион размыт.

### `art_key_river` — река
С трибуны / от ворот. Тёмная вода, трубы, закат. Ржавые ворота на переднем плане. Бардин спиной.

### `art_key_apartment` — квартира
Сидит на полу среди коробок. Свет из окна. В руках фото с женой. Печаль без горечи-плаката.

### `art_key_factory` — завод
14-летний бьёт мячом в железные ворота. Длинные тени. Отец — силуэт без лица.

### `art_key_fall` — падение
Колено не держит. Жёлтая трава. Смотрит в небо. Тень Глока или тренера. Боль на лице, не splatter.

### `art_key_whistle` — после свистка
Один на пустом поле. Серое небо. Снятые бутсы в руках.

### `art_key_epilogue` — эпилог
Новая дешёвая квартира. Мяч на полу. Смотрит в окно на ту же реку. Спокойное лицо.

## 7. UI и переходы

| элемент | правило |
|---|---|
| цвета UI | приглушённый серый, тёмно-синий, выцветший жёлтый акцент |
| шрифт | крупный, лёгкая потёртость, как старая машинка; не футуризм |
| кнопки выборов | три круга: синий / жёлтый / серый |
| фон меню | стадион + река |
| вход в прошлое | чёрный → размытый кадр локации → резкость; виньетка, зерно |
| триггер-воспоминание в матче | глубокий фокус, стадион глуше, одно изображение прошлого; сепия или холод, затемнение краёв |

Не рисовать в UI случайные цифры статов. Статы скрыты (`soft_stats` / сюжетная библия).

## 8. Техтребования кадра

| параметр | значение |
|---|---|
| `art_resolution` | 1920×1080 или 3840×2160 |
| `art_format` | png или psd со слоями |
| `style_processing` | реализм + плёнка, зерно |
| `ken_burns` | медленный pan/zoom на still |
| `page_flip` | для матч-комикса |
| `ai_as_is_allowed` | false |

Имена файлов как в пайплайне: `art/<type>/<id>_v##.png`.

## 9. Рецепты промптов по типу

### Портрет
```
{prefix}, waist-up portrait of {anchor}, locker-room warm lamp OR overcast stadium, emotional interiority, shallow depth, film grain
```

### Локация без героя
```
{prefix}, establishing shot of {location anchors}, empty of crowds or sparsely populated, no hero, architecture as mood
```

### Ключевой кадр с героем
```
{prefix}, {composition from card}, Aleksei Bardin {pose}, {palette}, story still not promotional key-art gloss
```

### Флэшбек
```
{prefix}, memory haze, slight vignette, {year} details, not a time-travel VFX plate
```

## 10. Формулы / баланс / локализация

### 10.1 Production
```
brief + locked refs + AI draft + human pass + engine check = shippable
```
Почему: соло и мало опыта; сырой ИИ палится и ломает тон.

## 11. Human pass checklist
- [ ] Кроп под бабблы/UI
- [ ] Палитра библии, не дефолт модели
- [ ] Лицо = portrait sheet
- [ ] Нет артефактов, водяных знаков, лишних пальцев, каши-текста
- [ ] Трибуны не «Камп Ноу»
- [ ] Бардин не выглядят на 24
- [ ] Зерно/линия стыкуются с соседними кадрами
- [ ] Размер/mips, читаемость на Low

## 12. Acceptance
1. Prefix и negative стабильны.
2. Обложка и лицо героя узнаваемы.
3. Западная трибуна закрыта, река за воротами есть.
4. ИИ-кадр без pass не в билде.
5. Матч не выглядит как футсимулятор.
